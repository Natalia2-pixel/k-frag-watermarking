# Blind crop threshold recovery v1

This local-only experiment freezes the non-promoted step-450 20-bit candidate and soft authenticated decoder v2. It distinguishes protocol k-of-n recovery, grid-aware erasure control, blind arbitrary-crop synchronization, and provisional content-state classification.

Packets are indexed regional code symbols jointly authenticated through threshold reconstruction of a distributed keyed authenticator; the eight-bit regional shares are not individually strong MACs. Candidate identities are accepted only by exact 64-bit HMAC reconstruction and verification against a bounded public source registry.

The blind search receives only a 256x256 questioned crop representation. Geometry hypotheses are deterministic and bounded. Crop coordinates, original grid positions, expected packets/tokens, and oracle survival labels are unavailable until post-decision evaluation. Fixed content authentication remains unavailable, so neural conflicts remain uncertain rather than being promoted to manipulated.

Stage E remains disabled and neural_stage_passed remains false regardless of outcome.
